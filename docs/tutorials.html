01 · 安装

安装与首次启动

Windows 与 Android 两种安装包的区别、装好后第一步做什么。

Windows 端

Windows 提供两种形态，内容完全一致，任选其一：

  • 安装版（Setup 安装包）：一键安装，写入开始菜单与桌面快捷方式，卸载时清理干净。适合长期固定在电脑上使用。
  • 绿色便携版（zip）：解压即用，不写注册表、不装到 Program Files。适合 U 盘携带、多机轮换、或不想留安装痕迹的场景。整个文件夹就是全部程序，拷到哪放哪。

下载

从官网「下载」区选渠道：蓝奏云 / 银盘 / GitHub 解析 / GitHub 直链，四个渠道指向同一份构建产物（V0.8.3）。

安装或解压

安装版双击运行、一路默认；便携版解压到任意目录（避免中文路径与带括号的路径）。

首次运行

首次启动会联网确认版本可用性（闸门页「请先联网检测版本号」）。确认通过后进入注册/登录。

Android 端

APK 直接安装，Android 7.0 及以上。安装时系统可能提示「来自此来源的应用」，允许即可。装好后第一次打开时，会引导你完成数据读取权限（见第 3 章「数据目录与作业列表」）。

提示Shizuku 是免 Root 提取数据的工具，与 APK 分开发放。需要时用官网「服务与工具」区的四渠道下载 Shizuku，提取码 ets。

首次启动会看到什么

注册登录通过后，App 会播放一份新手引导（4 页横滑）：

  • 欢迎：五种题型、答案、范文、评分关键词，支持背题模式。
  • 精听与模拟考场：逐句区间播放、倍速、A-B 循环，复现考试流程。
  • AI（可选）：设置里配接口后才有；默认提供商是 Agnes 国内站 / 国际站，均可免费领取 Key。不配置也完全可用。
  • 数据在哪：电脑扫 %APPDATA%\ETS；手机需 Root 或 Shizuku 提取权限（设置里有引导）。

引导结束后自动进入页面内的互动教程（蒙层 + 锚定真实控件），作业页、详情页、AI 对话页、修改页各有一份；没看完可以随时在「设置 → 使用帮助 → 功能引导」里重放。

提示首次启动内置了两份演示作业，进正式使用后自动隐藏；想再看，在「设置」里打开「演示数据」开关即可。
02 · 账号

账号与授权

注册登录制、授权时长、到期/封禁/多开、离线规则。

注册与登录

软件本身免费，但采用账号注册登录制：先注册账号，再登录激活。闸门页顶部有「注册 / 登录」切换，账号 6–16 位字母数字，密码至少 6 位。

  • 记住账号后，下次启动会显示圆形头像一键登录，不必再输密码。
  • 「设置 → 个人账号」可修改密码、切换账号、退出登录。
  • 机器码随账号绑定显示在「账号与授权」卡里，用于多开限流识别。

授权时长

每个账号有使用时长，由作者后台统一分配与控制，App 内「账号与授权」卡会显示剩余时间与到期时间。软件本身不收费，时长不是付费解锁——是作者对免费软件的资源分配。

「剩余时间」按到期时间与当前时间的差值实时算出来：不足一天显示到小时，不足一小时显示到分钟；剩余超过 30 年时直接显示「长期有效」，不再显示具体天数。

  • 到期：本地时钟到点即强制下线，回拦截页，提示「账号已到期」。联系作者续期后，点「重新检测」即可恢复（不用重新登录）。
  • 封禁：服务端明确拒绝。保持登录态，提示原因，需联系作者解封。
  • 多开超限：同一账号同时在线数超过后台配置上限，新设备会被踢下线；在保留设备上重新检测即恢复。
  • 作者保留对授权时长、功能范围、账号状态与版本可用性的最终控制权。

离线规则

  • 首次登录需联网：注册、换 Token、取到期时间都要联网。
  • 有效期内可离线：答案解析、精听、模拟考场、悬浮窗、修改栏全部在本机完成，拔掉网线照常用。
  • 长时间断网后首次启动可能需联网确认一次版本（闸门页「请先联网检测版本号」）。
  • AI 对话需要联网（走你自备的接口），其余核心功能不需要。
注意断网期间本地到期判定仍生效（拿已知到期时间与本地时钟比，到点立刻拦）。服务端周期检测（3 分钟一次）与启动检测都会在联网后刷新到期时间。
03 · 数据

数据目录与作业列表

数据从哪来、读不到怎么办、列表怎么组织、怎么刷新与标记完成。

默认扫描目录

平台默认目录说明
Windows%APPDATA%\ETS即 C:\Users\<用户>\AppData\Roaming\ETS。E听说 客户端下载作业就放这里。
Android/storage/emulated/0/Android/data/com.ets100.secondary/files/Download/ETS_secondary/resource需要先授予「所有文件访问」权限；Android 11+ 有系统限制，走下面的四通道提取。

在「设置 → 数据目录」可追加自定义目录（比如你把作业拷到了别的盘）。Windows 端还能直接「打开数据目录」定位文件夹。

Android 11+ 读不到 Android/data？

这是系统限制：Android 11 起，即使授予「所有文件访问」，也读不了其他应用的 Android/data。App 内置四种提取通道，在「设置 → 数据目录 → 选择工作授权模式」里勾选已就绪的通道，再点「用 X 开始提取」：

通道适用操作要点
Shizuku免 Root 真机（最稳）装 Shizuku → 开发者选项开无线调试 → Shizuku 配对启动 → 回本 App 点授权 → 开始提取
Root（libsu）Mumu 模拟器、已 Root 真机Mumu 设置 → 其他设置 → 开启 ROOT，回本 App 直接选 Root 提取
直读（零提权）部分机型 / 模拟器可直接读无需授权，选中即提取
SAF（系统授权）系统文件选择器兜底点按钮选 E听说 的 resource 目录授予访问，再提取

提取会把 E听说 数据拷贝到本应用私有目录（Android/data/com.eets.e_ets_helper/files/ets_data），之后扫描、精听、悬浮窗全部正常。每次 E听说 重新下载作业后，回作业页点一次「刷新」即可同步。

不想用提取？电脑上用 adb 直接拷： 
adb pull /storage/emulated/0/Android/data/com.ets100.secondary/files/Download/ETS_secondary/resource ./ETS_data
把 ETS_data 拷进手机的 ets_data 目录，再在「设置 → 数据目录」追加该路径。

作业列表怎么组织

  • 递归扫描数据目录，按「文件夹名（数字）- 标题 - 类别」收纳；同类多条折叠成一个文件夹。
  • 单词组进入单词本页，可隐藏释义自测。
  • 顶部 chip 按题型筛选：全部 / 模仿朗读 / 角色扮演 / 故事复述 / 对话跟读 / 单词跟读，括号里是文件夹数量。
  • 搜索可查标题或题号；右侧切排序（时间正倒序 / 标题）与视图（详细列表 / 紧凑网格）。
  • 点卡片进详情；长按进入多选，可全选、标记完成（收纳到「已完成区」）、永久删除。

刷新

点右下角「刷新」会重新读取 E听说 数据；手机上会先走当前指定的提取通道（Root / Shizuku）再扫描。通道在「设置 → 数据目录」里可指定；未指定时自动按可用顺序试。

没有可用通道提示「暂无可用通道」时，先去「选择工作授权模式」里勾选并启用一个已就绪的通道，再回作业页刷新；会按现有目录先扫一遍。
04 · 答案

答案与五种题型

每种题型怎么排版、答案怎么呈现、标题怎么来、背题怎么用。

五种题型的专属渲染

解析 E听说 本地数据后，五种题型各有专属排版，答案逐句对照，不再是裸文本：

题型排版特点常见用途
模仿朗读原文 + 逐句对照，含原版考试视频（可播放）跟读纠音、听辨节奏
角色扮演多角色对话分列，各角色文本与音频对应对话跟读、语境记忆
故事复述范文 + 评分关键词高亮，逐句时间轴复述练习、要点覆盖
对话跟读逐句 A/B 分列，每句独立可播精听、影子跟读
单词跟读单词 + 释义 + 例句，支持隐藏释义自测词汇记忆、拼写自测

标题三级策略

作业标题不靠猜，按优先级三级回退：

  1. 模板提取：直接读 paper.Jason 里的 tz_mc、topic、read_title 等字段。字段齐全时一步到位。
  2. 自适应匹配：模板字段缺失或为空时，按题号、文件名等上下文推断。
  3. AI 智能匹配：前两级都不可靠时，调 AI 从原文提炼一个简短标题（不超过 20 字）。
提示AI 标题结果有缓存：同一份作业重复打开不会重复生成，不重复扣额度。

背题模式

详情页顶栏「背题」一键隐藏全部答案，用于自测；点任意模糊处或再点一次即可恢复。单词组进入单词本页后也能隐藏释义自测，适合考前默写。

未知题型

遇到不在五种里的新题型，会走「未知题型 AI 自适应识别」：AI 读原文结构，按题型语义归类后渲染；识别结果同样有缓存。

05 · 精听

精听与播放

倍速、A-B 循环、逐句播放、进度条拖动、跟读高亮——把音频条用透。

倍速

支持 0.25x – 3.0x，可手输两位小数（如 1.35）。常用节奏：0.5x 磨耳朵、0.75x 跟读、1.0x 原速、1.5x–2.0x 冲刺。

A-B 循环

点音频条上的「A」设起点、「B」设终点，之后只在这段之间循环。适合死磕某一句：A 设句首、B 设句尾，反复听不跑题。取消时点已设端点旁的清除图标。

逐句播放

有逐句时间轴（begintime~endtime）的题型，每句右侧有 ▶ 按钮，点它只听该句区间，不从头播。配合背题模式：先遮住答案听原音，再逐句对照。

进度条拖动

进度条支持拖动定位（指针按在条上左右滑），松手即跳到目标时刻。跟读高亮打开后，播放时逐句染色：已读句与当前句高亮，当前句加粗。

跟读音色（朗读）

「外观」卡里的朗读音色用微软 Edge 神经语音在线合成，不需要本机装英语语音包。选一种音色后，答案/范文/关键词可点读，方便跟读对照。

精听工作流第一遍原速听大意 → 逐句 ▶ 定位卡壳句 → A-B 循环该句 → 0.5x–0.75x 跟读 → 开跟读高亮对照 → 切 1.5x 冲刺检验。循环直到整篇跟得上。
06 · AI

AI 配置与使用

多提供商、多模型、思考档位、多模态、实时对话、智能排版，以及 Agnes 双站怎么领 Key。

配置一个提供商

「设置 → AI 配置」填三个东西，即可用任意 OpenAI 兼容接口：

  • Base URL：接口根地址，例 https://api.deepseek.com/v1。
  • API Key：你的密钥，填在对应提供商下。
  • 模型：例 deepseek-chat / glm-4-flash / kimi-k2。

每个提供商可配多个模型；配好后选一个为当前模型。多模型按优先级排，一个失败自动切下一个，会提示「已切换到下一个模型」。

Agnes 国内站 / 国际站

软件内置了 Agnes国内站 / Agnes国际站 两站，注册即送 API Key、不限额度、无需充值，填 Key 即用：

  • Agnes国内站（platform.agnes-ai.cn）：更稳定，但需实名。
  • Agnes国际站（platform.agnes-ai.com）：免实名，可能没那么流畅。
命名两站统称「Agnes国内站 / Agnes国际站」，各有独立站点与控制台。两站 Key 互不通用，按你注册的那一站填对应提供商。

思考档位

  • Agnes 模型：出厂只有关 / 开两档（配置层锁死），够用就行。
  • 其他模型：默认低 / 中 / 高，可自定义到 超高 / 最高。思考开时 temperature 固定 1，预算随档位注入（不同模型预算上限不同，接口不支持就关思考）。

多模态（图片输入）

模型标记「多模态」后，AI 对话可附图；图片只在你主动发送时才随请求发出去，不上传作业数据。

AI 实时对话

详情页「AI 对话」入口，多轮流式输出，历史本地保存、各自独立会话。回车发送、Shift+Enter 换行；图片按钮附图；生成中可点「停止」打断，断点还能「继续生成」；开思考后思考过程实时显示可折叠，气泡下方是本次 token 与速率。

AI 智能排版

详情页 AI 菜单四项，全部有结果缓存（重复打开不重复扣额度）：

  • 智能解析：按 E听说 语义整理成 Markdown（重点词汇短语表格等）。
  • 全文翻译：逐段对照英中翻译。
  • AI 标题：提炼不超过 20 字的简短标题。
  • 未知题型自适应识别：新题型按语义归类渲染。

隐私与免责

  • AI 功能仅在用户主动触发时，把内容发往你自备的接口；不配置就完全用不到，不影响答案 / 精听 / 考场。
  • 作业数据不上传；AI 输出仅供参考。
  • AI 是否免费取决于你接入的服务商（Agnes 双站免 Key 费、不限额度；其他服务商看各家）。
报错先看这两处① Base URL 是否带了版本段（/v1）；② 模型名是否精确（deepseek-chat 不是 deepseek）。设置页的「测试连接」按钮会直接报「发生什么 + 怎么办」。
07 · 考场

模拟考场

按原软件 ctrl 流程复现考试：播放 → 倒计时 → 录音 → 回放，可中途跳过。

流程

播放

先播一遍题面/范文，和真实考试一致。

倒计时

按题目时长开始计时，营造考场压力。

录音

对着麦克风跟读，App 录下你的声音。

回放

播回放对比，找出跟读差距。

中途跳过

每步都能跳过，不必从头走完整条流程；适合只想练某一步（比如只录音）的情况。

录音权限

Android 首次录音会要麦克风权限；Windows 用系统默认麦克风。没开权限就录不了，到系统设置里放行后再试。

用法考前一天完整跑一遍计时（播放+倒计时），习惯节奏；平时只开「录音 + 回放」跟读纠音，不必每次走全流程。
08 · 悬浮窗

悬浮窗（Android）

折叠圆形 Logo 小球常驻屏幕，点开答案；Windows 端用窗口置顶加快捷键代替。

打开悬浮窗

壳层顶栏右上角有悬浮窗按钮（在教程按钮左边），全局生效：切到别的 App 也能用。打开作业详情页后点它，就把当前作业的答案推到系统悬浮球。

开权限

系统「设置 → 应用 → 特殊应用权限 → 显示在其他应用上层」允许本应用；未授权时按钮会提示去开权限。

点悬浮窗按钮

答案收起成圆形 Logo 小球，拖到屏幕任意位置。

点小球展开

展开当前作业答案面板，切回别的窗口也随时能看。

A B C 分段与切作业

套题（一份卷子的 A/B/C 三段）打开后，悬浮窗顶部出现分段切换按钮；单条作业没有分段则不显示。右上角三点菜单可切换其他作业，选哪份就把哪份的答案装进悬浮球。

外观

  • 配色跟随主题：默认 follow 跟随 App 主题色；也可固定浅色 / 深色。
  • 大小与不透明度（0.4–1.0）在「设置 → 悬浮窗」里调。

Windows 端

Windows 端已下线悬浮球，用两个替代：

  • 窗口置顶：让 App 窗口浮在 E听说 上方，切窗口也露着。
  • 全局快捷键 Ctrl+Alt+E：呼出 / 收起主窗口，随时切换。
入口「设置 → 悬浮窗」卡（手机端）/「设置 → 窗口」卡（电脑端）可打开设置面板；开关、配色、大小、不透明度、置顶、快捷键都在这里。
09 · 修改栏

成绩与时间修改

本机 HTTPS 代理拦截 E听说 的成绩提交接口，按你的规则改写成绩与完成时间，数据全程不出本机。

原理（一句话说清）

开启后，本机 127.0.0.1:端口 起一个内置代理，把系统流量引到它；E听说 提交成绩的请求命中该代理时，按下方规则改写「成绩」与「完成时刻」再放行。关闭总开关会自动还原代理，不留痕迹。

开总开关

「修改」页第一张卡：抓包拦截总开关。开启即起代理。

设端口

默认端口可改；改完引擎自动换端口监听，系统代理跟着指到新端口。

设规则

填目标总成绩 / 完成时间（见下）。

装证书

HTTPS 拦截需要信任自签根证书（Windows / Android 步骤见下）。

设系统代理

把流量指到引擎；关闭总开关时自动还原。

目标总成绩

填这份作业最终想要的总分（如 60），引擎按各小题满分占比自动分摊到每道题。允许超过满分。高级模式可按题型精确指定每小题得分（不分摊，直接按你填的值）。

修改完成时间

按天 / 时 / 分 / 秒填一个时长，提交时后台自动把完成时刻提前这么久：填 1 分 30 秒，完成时间看起来就是 1 分 30 秒之前。全空表示不修改；填 0 表示按提交时刻上传。

证书安装

拦截 HTTPS 要信任 App 自签的根证书（名字 EtsHelper Capture Root CA）：

平台证书去向安装
Windows拷到文档目录 EtsHelperCA.pem「安装证书到当前用户」→ 装进当前用户受信任的根证书库，状态卡自动感知。
Android拷到 /sdcard/Download/EtsHelperCA.pem（需 Root 导出；无 Root 会提示文件原路径）系统「设置 → 安全 → 证书 → 安装 CA」选该文件；装完状态卡自动感知。
注意证书生成失败会提示；重装前旧证书仍生效。状态卡会显示「证书已安装 / 未安装 / 生成中」。

还原与风险

  • 关闭总开关 = 自动还原系统代理，E听说 恢复走原始通道。
  • 全程数据不出本机：解析、改写、证书、代理都在本地。
  • 仅供学习研究使用；请对自己的修改行为负责。
风险改成绩/改完成时间属于对 E听说 提交数据的本地改写，提交后 E听说 端记录会按改写后的值呈现。请自行把握使用边界，勿用于不正当用途。
10 · 设置

外观与效率设置

风格、主题色、布局、音色、窗口/悬浮窗、实验性功能——都在「设置」里。

外观

  • 软件风格：默认 Material 3，可一键切 iOS 26 玻璃模糊风格。
  • 深浅色：跟随系统 / 浅色 / 深色。
  • 布局：自动 / 平板·电脑（左侧菜单）/ 手机（底部菜单）。
  • 跟读高亮：播放时逐句染色，当前句加粗。

主题色

8 个预设色板一键切换，也可打开调色板自定义任意颜色。换色后悬浮窗背景、视频进度条拖块等都会跟着变。

  • 保真取色：选什么色，主色就是什么色，不会被系统调色板拉深、拉灰。
  • 渐变色：可用一条渐变当主题色——预设渐变直接选，也可以自己分别调两端颜色。
  • 彩虹（动态）：主色随时间平滑循环变色。
提示深色主题下不会把白字硬套在浅底上——文字颜色始终跟随所在容器的前景/背景配对，深浅两套主题都保证可读。

朗读音色

朗读音色用微软 Edge 神经语音在线合成，不需要本机装英语语音包。选一种音色后，答案/范文/关键词可点读对照。

窗口（电脑）/ 悬浮窗（手机）

  • 电脑：「窗口」卡。窗口置顶 + 全局快捷键 Ctrl+Alt+E（呼出/收起主窗口）。
  • 手机：「悬浮窗」卡。悬浮球大小、不透明度、配色（见第 8 章）。

实验性功能

「预览功能」开关默认关；开启后可在「修改」页预览尚未正式上线的抓包改分（目前无效果）。随时可关。

12 · FAQ

常见问题

官网 FAQ 的扩展版，把「为什么」也讲清楚。

需要 E听说 账号吗？

不需要。App 只解析 E听说 客户端已下载到本机的数据文件，不碰 E听说 账号、不上传数据。但用 App 本身要注册并登录 E听说助手账号（见第 2 章）。

软件收费吗？

软件本身不收费。账号授权有使用时长，由作者后台统一分配与控制；到期 / 封禁 / 多开超限会被强制下线，续期解封后恢复。作者保留最终控制权。

能离线用吗？

首次登录需联网；登录后在授权有效期内，答案解析 / 精听 / 模拟考场 / 悬浮窗 / 修改栏全部本地完成，断网照常用。长时间断网后首次启动可能需联网确认一次版本。AI 对话需联网（你自备接口）。

会上传我的作业数据吗？

不会。解析全在本地；只有你主动用 AI 时，内容才发往你自备的接口（含图片附图时）。

AI 必须配吗？

不必。答案、精听、模拟考场、悬浮窗、修改栏都不依赖 AI。配了只是多一个解读 / 翻译 / 对话入口。

安卓读不到数据？

Android 11+ 系统限制读不了别的应用 Android/data。用内置四通道（Shizuku / Root / 直读 / SAF）提取一次即可（第 3 章）。

Agnes 国内站和国际站怎么选？

内置两站都免费、不限额度、注册送 Key。国内站更稳但要实名；国际站免实名但可能没那么流畅。按你注册的那一站填对应提供商，Key 不通用。

修改成绩会不会被 E听说 识别？

改写发生在你本机提交前的代理层，E听说 端记录按改写后的值呈现。是否触发 E听说 自身风控由其决定，App 不干预——请自行把握使用边界（第 9 章）。

多开会不会顶掉别人？

同一账号同时在线数超过后台上限时，新设备会被踢；保留的设备不受影响。超限属正常限制，不是 bug。

网页打不开？

主站 klp-kulipa-24.github.io/ETS-TOOLS；国内访问不了用备用站 ets-tools.klp-kulipa.workers.dev（内容相同）。更新检查也是主站优先、备用站兜底。
